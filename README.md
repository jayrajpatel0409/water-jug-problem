# AquaMind — The Water Jug Puzzle Game & AI Search Visualizer

An interactive educational web application designed for **Artificial Intelligence & State-Space Search** demonstration.

It provides a clean, visual representation of the classical **Water Jug Problem**:
- **Watch & Play Modes**: Watch automated step-by-step solutions or play manually.
- **Illustrated Water Jugs**: Real-time fluid animation, graduation ticks, and target goal indicators.
- **Synchronized Search Tree**: Interactive state-space tree showing explored states, solution paths, and goal states.
- **Search Algorithms**: Breadth-First Search (BFS) and Depth-First Search (DFS).
- **Mathematical Solvability**: Real-time Bézout's Identity and GCD calculation.
- **Performance Metrics**: Moves count, explored states, found nodes, peak queue size, and execution time.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Run Automated Tests
```bash
npx vitest run
```

### Build for Production
```bash
npm run build
```
